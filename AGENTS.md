# AGENTS.md

This repo is for setting up a voice agent which can schedule an appointment with someone on my Google Calendar.

## Agent skills

### Issue tracker

Issues live as GitHub issues in `JacobStephens2/voice-agent-scheduling`, managed with the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

The five canonical triage roles, each label string equal to its name. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: `CONTEXT.md` and `docs/adr/` at the repo root. See `docs/agents/domain.md`.
